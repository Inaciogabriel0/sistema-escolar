Sistema de Autenticação Full Stack com Laravel e Vue.js

Este projeto foi desenvolvido com o objetivo de aprofundar meus conhecimentos em arquitetura Full Stack, trabalhando o Front-end e o Back-end de forma separada para compreender melhor o fluxo de comunicação entre aplicações modernas.

No Back-end, utilizei o framework Laravel para construção da API, implementando autenticação baseada em JWT (JSON Web Token), gerenciamento de rotas, validações e controle de usuários.

No Front-end, desenvolvi a interface utilizando Vue.js juntamente com Vuetify para a criação da interface visual, Pinia para gerenciamento de estado e Axios para comunicação com a API.

Durante o desenvolvimento, o foco principal foi entender na prática:

A separação entre Front-end e Back-end;
O fluxo de autenticação utilizando JWT;
O envio e armazenamento de tokens;
A comunicação entre cliente e servidor utilizando requisições HTTP;
Gerenciamento de estados no Front-end;
Estruturação de APIs REST;
Proteção de rotas autenticadas;
Organização de projetos Full Stack modernos.

Este projeto serviu como uma experiência prática para fortalecer minha base no desenvolvimento web moderno e compreender melhor como diferentes tecnologias se conectam em uma aplicação real.
